# UX notes — calibration device test · 2026-07-28

Observations collected from live screenshots during field test 8 (the
calibration device pass). These are **notes for later**, not tickets —
severity-sorted so the next UX pass can triage. Functional defects found the
same day (silent chirp, stale-clock arm, sheet never rendering) were fixed
during the test and are documented in the commits, not here.

## Worth fixing

1. **Off-scale values clamp invisibly on the caliper.** The bogus 2232 ms
   profile drew its settled line pinned at the 600 ms axis edge — the hero
   said 2232 while the scale silently implied ~600. Any value past
   `scaleRangeMs` renders indistinguishably from one *at* the edge. Needs an
   off-scale affordance (clipped-arrow tell, or an axis that stretches),
   especially since a bad measurement is exactly when the visual should look
   wrong.

2. **Raw routeId leaks into user-facing copy.** The gate said "New here:
   speaker", the shelf row and detail title say "speaker" — lowercase
   plumbing vocabulary — while the guided sheet says "Phone speaker" for the
   same route. `CalibrationProfile.deviceName` stores the routeId when
   `routeName` is null. One humanising fallback ("Phone speaker") applied at
   a single point would fix gate, shelf, and detail together.

3. **"Calibrate again" is below the fold.** On a Pixel 10 Pro the detail
   pane's primary action needs a sheet-drag to reach. The partially-expanded
   `ModalBottomSheet` default hides the one thing the pane exists to offer;
   it should open expanded or the content should fit the peek height.

4. **The detail caliper's right axis label clips** — renders "60…" with the
   final digit cut by the recessed well's inset. Label needs padding inside
   the well, or the well needs to account for label width.

## Worth considering

5. **Attempt debounce.** Rapid Try-again taps used to contaminate
   measurements via the stale-clock bug (fixed in core — t0 now comes from
   fresh capture), but the UI still allows starting a new attempt the moment
   the last one fails. A short cooldown, or disabling the pill while the
   previous chirp's audio could still be in the 12 s capture history, would
   remove the residual risk class entirely.

6. **Landscape needs a pass.** The gate rendered correctly in landscape, but
   its primary pill sat at the very bottom edge of the screen. General
   landscape ergonomics were already flagged in ux-audit-2026-07 (#13);
   calibration sheets should be included in that pass.

7. **Single-sample caliper reads as empty.** With one retained sample
   coincident with the settled line (and doubly so when off-scale, see #1),
   the detail well looks blank. The spec's single-tick treatment exists, but
   at 20 dp row height and one tick the visual carries almost nothing —
   worth checking against the populated preview once referee samples
   accumulate in real use.

## Already known / tracked elsewhere

- Debug overlay occupies the top third of every screen (field-phase
  artifact; tap-to-dismiss exists, full removal gated on end of field
  phase — ux-audit-2026-07 #4).
- TalkBack verification of the CFX-03 semantics still needs a device pass
  (tracked on CFX-03).
- The route observer reported "speaker" while physical audio still went to
  Bluetooth headphones ("Bose Ilse") — a route-truth mismatch above the
  app's own state, discovered when the chirp played into the user's
  headphones. Tracked as a follow-up finding in the field-test notes; the
  honest Failed copy handled it gracefully, but attribution ultimately
  trusts an observer that can lag physical routing.

## What the screenshots confirmed working

The first-contact gate (route-neutral copy, decline path, re-raise for a
still-unprofiled route), gate-wins sheet precedence, mid-flight route-change
cancellation, the evenhanded Failed copy, the shelf row anatomy (name /
tabular value / provenance qualifier / `· Connected` tell / caliper strip),
the detail hero staying `ink`, recalibration preserving `createdAtMs` while
updating the value, and the full measurement pipeline ending in a plausible
**153 ms MEASURED** phone-speaker profile.
